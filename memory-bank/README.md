# Memory bank (archived)

These files are a snapshot of the earlier 3D cyberpunk/space portfolio concept:
a single-page site with Three.js, service pricing, and Google Forms lead capture.

That direction is retired. The files are kept for history and are not maintained.

Canonical documentation lives at the repository root:

- `README.md` - what the site is, how to run it, publishing rules
- `ARCHITECTURE.md` - pages, assets, content pipeline, CI and deploy
- `DESIGN.md` - tokens, type, layout, motion, accessibility
- `ROADMAP.md` - shipped log and open checks
- `NEXT.md` - active work only
- `DONE.md` - completed work moved out of the backlog
