# eyewright recording checklist

## Before

- [ ] Source checkout available; `examples/gate.json` exists.
- [ ] `laya-serve` healthy on `127.0.0.1:8000`.
- [ ] Ollama healthy on `127.0.0.1:11434`.
- [ ] `eyewright --version` returns `0.4.0`.
- [ ] Disposable state text; no client data, keys, or personal paths on screen.
- [ ] Terminal font 18–20 pt; prompt shortened; notifications off.
- [ ] OBS scene and mic tested; 1080p/30 or 60 fps.
- [ ] One rehearsal run with the exact commands.

## During

- [ ] 75 seconds, no rushed trace.
- [ ] Show the real decision and trace.
- [ ] Show the opt-in cloud boundary if configured.
- [ ] Never fabricate a successful gate or hide an error.

## After

- [ ] Watch once with sound; check no secrets or private paths.
- [ ] Upload unlisted; add title/description/links.
- [ ] Add demo + GitHub links to `work/eyewright.html` and the Work record.
- [ ] Add poster frame.
- [ ] Run the site link check.
- [ ] Mark the blocker in `NEXT.md`.
