# Portfolio agent rules

- PLEASE NO EM DASHES FOR ANY REASON. No U+2014 in HTML, CSS, JS, Markdown, comments, or commits. Use commas, colons, periods, or plain hyphens.
- Canonical docs: `README.md`, `ARCHITECTURE.md`, `DESIGN.md`, `ROADMAP.md`, `NEXT.md`.
- `_project-docs/` is generated. Never hand-edit it; edit the source project doc.
- Before pushing: `npm run check:static`. After deploy: `npm run smoke`.
- Do not switch Pages back to the legacy branch builder.
