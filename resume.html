Fixture

Python, FastAPI, FreeCAD, Blender, Ollama - public

  • Built a local-first harness that turns chat into programmatic CAD operations in FreeCAD and Blender through one JSON-schema tool contract: named tools only, confirm-before-mutate, undo-wrapped changes, and no model-written code execution.
  • Benchmarked 13+ local planners and 4 cloud models on a 60-case suite (96.7-98.3% vs 57.6-74.6% for the closest open-source assistant); gate PASS: pytest 140, FreeCAD 92/0, Blender 29/0.

  • Built STEP/STL desk cases (4-piece laptop cradle, 2-piece under-desk shelf) and a Blender scan-cleanup tool that exports watertight STL; the keyboard case stays private.
