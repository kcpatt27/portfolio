  1. 2026 · November

    Fixture - release candidate

    A local-first harness that drives FreeCAD and Blender through one schema-validated tool contract. Gate PASS at 140 pytest, FreeCAD 92/0, Blender 29/0; two scripted STEP/STL desk cases.

    Public
  2. 2026 · October

    AI Security Layer (AISL) - agent execution runtime

    A capability-gated execution layer where the model cannot grant itself authority. Policy evaluation, taint tracking, egress DLP, and a signed hash-chained audit log, documented as 39 security claims, 32 ADRs, and 716 tests.

    Private
  3. 2026 · October

    eyewright - v0.4.0

    A local-first decision core published to PyPI: a measured committee of local models behind one typed call. In a 2,000-decision replay, the selected policy reached 88.9% acted accuracy at 22.5% coverage.

    Published
  4. 2026 · October

    mcp-weight - published to npm

    A read-only CLI that reports the context cost of MCP tool schemas across six clients. 517 downloads in its first month; a broken server stays a row instead of failing the scan.

    Live
  5. 2026 · July

    Living State Machine - research closure

    A local-first LLM memory system with six ablatable mechanisms, 1.000 vs 0.100 preference recall at matched budget, and 240+ tests. Paper in preparation.

    Public
  6. 2026 · June

    allSoft - robot simulation validation

    A YAML-driven simulation-in-the-loop harness: PX4 SITL and Gazebo in Docker, MAVSDK missions, and JSON plus SQLite artifacts for regression comparison. 4/4 reference scenarios pass live.

    Private
