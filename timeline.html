Timeline

What is done.

A record of shipped work and honest endings. No roadmaps, no promises — just the things that exist and what came of them.

  1. 2026 · OCTOBER

    MemVid MCP — retired

    An MCP server that packaged text into searchable memory banks for AI assistants. Published to npm and benchmarked (57× faster startup, 1,900× faster cached search), then archived when the upstream MemVid format was deprecated. Kept as a case study rather than deleted.

    ARCHIVED
  2. 2026 · OCTOBER

    SQWease — shipped

    A zero-dependency language-learning web app with flashcards and spaced repetition. Five languages and roughly 11,500 words, built from a reproducible data pipeline, with Lighthouse accessibility 1.0 on all six pages.

    LIVE
  3. 2026 · MARCH

    This site — rebuilt as a documentation surface

    Moved from a single page to a multi-page static site with a config-driven content pipeline, then hardened after a GitHub Pages failure caused by committed symlinks.

    LIVE
  4. 2026 · JANUARY

    Global Information Portal — v1.0

    An interactive map of 240+ countries with 100+ metrics each from the CIA World Factbook, running entirely in the browser. Progressive caching cut the initial load in half and repeat visits to under a second.

    LIVE
  5. 2025 · PUBLISHED

    “Working with AI” — developer guide

    A 25,000-word tutorial on building software with AI coding assistants, with role-specific tracks and case studies drawn from production projects. The strongest technical-writing artifact in the portfolio.

    PUBLISHED
