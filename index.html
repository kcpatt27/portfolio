No. 01

Fixture

Status Release candidate · Public

A local-first harness that drives FreeCAD and Blender through one JSON-schema tool contract. The model proposes named tools; the client confirms, executes, and undo-wraps them.

Stack Python · FastAPI · FreeCAD · Blender

Evidence
Gate PASS: 140 pytest, FreeCAD 92/0, Blender 29/0. A 60-case benchmark put Fixture at 96.7–98.3% against 57.6–74.6% for the closest open-source assistant. The release tree includes two scripted STEP/STL desk cases: a 4-piece laptop cradle and a 2-piece under-desk shelf.

Field note 02

Before software

A note on method

Before software, I spent eight years as a music producer. The habits carried over: listen closely, cut what does not earn its place, and finish the thing.

Curiosity became a practice: build the smallest system that can be trusted, then write down what happened - including the parts that failed.

Local-first by default.
Models run on the machine that owns the data unless there is a reason not to.
Deterministic boundaries.
The model proposes; a schema, a policy, or a test decides.
Evidence over claims.
Benchmarks, logs, and regression gates, including the cases that fail.
Small tools that compose.
One job each, wired together, rather than one opaque system.

What is done

Six latest from the timeline

  5. 2026 · July Living State Machine, research closure. A local-first LLM memory system at 1.000 vs 0.100 preference recall at matched context budget, with 240+ tests and a reproducible ablation runner.
  6. 2026 · June allSoft, robot simulation validation. A YAML-driven simulation-in-the-loop harness: PX4 SITL and Gazebo in Docker, MAVSDK missions, and JSON plus SQLite artifacts for regression comparison. 4/4 reference scenarios pass live.
