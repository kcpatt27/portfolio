Living State Machine

Gated, ablatable memory for long-horizon preference recall around a frozen language model

Kalen Patterson · Independent research · kcpatterson27@gmail.com

Long-horizon assistants need memory that is cheap, inspectable, and resistant to drift. This report describes Living State Machine (LSM), a local-first wrapper around a frozen language model that combines a compact dual state, tiered episodic memory, habituation, Hebbian association, gated writes, a deterministic verifier, and surprise-modulated plasticity. Every mechanism is ablatable through configuration. On a matched-budget preference-recall benchmark, LSM scored 1.000 against 0.100 for naive retrieval-augmented generation across three seeds; a harder decoy-heavy stress benchmark was treated as a stress test rather than a success metric. The gated writer reached an F1 of 0.98 and was necessary under decoy load, where always-store collapsed to zero. The report also documents three substantive negative results — a multi-timescale memory variant, an encoder verifier, and a Stentor-style recurrent core — plus one evaluation-harness fault that initially looked like a model regression. The central claim is deliberately narrow: under a matched context budget, structured, gated memory can outperform naive retrieval. It is not a claim that the wrapper beats a full-context model on every long transcript.

Keywords: long-horizon memory · retrieval-augmented generation · gated writes · state-space models · local-first AI · evaluation hygiene

1. Introduction

A frozen language model is stateless between calls. The common workarounds are prompt stuffing, retrieval-augmented generation, or a separate memory service. Each buys context at a cost: full history grows without bound, retrieved snippets are brittle under decoys, and an LLM-written summary can quietly turn an assistant's guess into a persistent fact. On consumer hardware the constraint is sharper: a 12 GB inference budget leaves little room for a second model to manage memory.

LSM studies a narrower question: can a compact set of inspectable, biologically inspired rules around a frozen model improve long-horizon preference recall at a matched context budget? The system is a wrapper, not a fine-tune. It keeps a small working state s_t, a durable episodic store, and a per-turn control loop. The research track closed in July 2026; this report is a technical account of the evidence, including what failed.

The contributions are:

  • A wrapper architecture in which every memory mechanism has a Null* implementation, so ablations are configuration changes rather than rewrites.
  • A deterministic facts-backed projection that replaces LLM-authored state after paraphrase errors were observed in live sessions.
  • A gated writer and verifier layer, plus evidence that gating is what survives a decoy-heavy stress bench.
  • A reproducible benchmark suite and a deliberately honest negative-results record, including a diagnosis of a false regression caused by one embedder choice.

2. Related work

Retrieval-augmented generation (RAG) conditions a model on retrieved passages rather than the full corpus [1]. It is effective when retrieval is clean, but it assumes the retrieved unit is useful in isolation. LSM instead retrieves from an episodic memory that has been filtered by a writer gate and scored by several signals.

Memory-augmented agents such as MemGPT treat the context window as a managed resource and move information between working and external memory [2]. Generative Agents maintain a memory stream with reflection and retrieval [3]. LSM shares the tiered-memory premise but differs in two ways: the language model is frozen and local, and the persistent state is rendered deterministically from structured facts rather than authored by the model.

Long-context transformers reduce the need for retrieval by extending attention [4], while state-space models offer linear-time sequence mixing [5]. LSM's Phase 2 explored a small state-space core, but the production path remained a wrapper; the trained core had to clear a no-regression gate rather than replace the baseline.

Habituation and associative learning are classic biological mechanisms [6], and regularization methods for sequential learning address a related stability problem [7]. LSM borrows the vocabulary — habituation, association, surprise, plasticity — but evaluates each mechanism as an engineering component, not as a biological claim.

3. System

3.1 Per-turn loop

Each turn follows a fixed control loop: embed the turn; score memory candidates with cosine similarity, habituation damping, association boost, and trust; retrieve the top k; update the working state; compose a prompt from the state projection and retrieved snippets; call the frozen model; score the outcome; run the verifier; write only what passes the gate; and update plasticity signals. The loop is deliberately small enough to inspect in logs.

3.2 State and memory tiers

s_t is a dual representation: a short text projection injected into the prompt (roughly 400–600 characters) and a dense vector used for retrieval conditioning. Durable memory holds verbatim atoms in LanceDB plus an episodic SQLite log. Fast, session, and durable tiers are connected by promotion, hit-count, vitality decay, and a background consolidator. The mental model is explicit: the state is a compressed, inspectable summary; durable memory holds the evidence.

3.3 Mechanisms

Habituation damps repeated low-value input; association boosts memories that co-occur with the current turn; trust carries outcome history; surprise-modulated plasticity amplifies the learning rate on correction-like turns. The facts-backed updater renders s_t.text deterministically from structured facts with recency, correction-aware slot ordering, and budget trimming. The LLM-authored summarizer remains only as an ablation. This change followed a live failure in which a vocative was absorbed into state as a game title and then inherited by every later turn.

3.4 Gated writing and verification

The verifier scores candidates rather than authoring text. Its five weighted components cover fact contradiction, identity drift, correction violation, list-merge errors, and length overflow. The score gates three surfaces: the writer (rejected text never becomes durable memory), the reply (one re-prompt with fix hints, then the lower-energy draft), and the legacy summarizer. The verifier is deterministic by default; a linear/hybrid learned head was evaluated, while an encoder variant was logged as a negative.

3.5 Ablation as dependency injection

Every mechanism sits behind a small Protocol with a Null* implementation. The eight benchmark configurations, the verifier family, and the state-updater family are therefore configuration flips. A run copies its YAML into the run directory with metrics.json, raw outputs, and logs; a run without its config is not treated as a run.

4. Experimental setup

The evaluation suite contains eight tasks: matched-budget preference recall (recall_pref_v1), a harder decoy/long-gap stress task (recall_pref_v2), habituation and association signal benches, memory-write precision, multi-session consistency, fact correction, and verifier calibration. Headline claims use seeds 0, 1, and 2; Phase 2 integration checks are seed 0 only and are labelled as such.

The primary baselines are naive RAG and a raw LLM with a matched context budget. A full-transcript raw LLM is reported separately because it is not matched: it sees the entire history and therefore answers a different resource question. Hardware was a single RTX 5060 Ti (16 GB VRAM, 32 GB RAM) running a frozen local model through Ollama. A one-time cloud burst on a RunPod L40S cost approximately $8.04 and consumed about 9.3 hours for QLoRA and small-core training. The local test suite finished at 241 passed and 3 skipped.

6. Negative results and failure analysis

6.1 Multi-timescale memory did not separate

A multi-timescale memory variant produced a small negative effect (Δ ≈ −0.05). The result was kept rather than tuned into the headline: on this bench, additional tiers added complexity without a measurable gain.

6.2 The encoder verifier collapsed

The MiniLM cross-encoder verifier scored 0.211 macro-F1 at n=13, effectively rejecting everything. With a small labeled set, the encoder had no room to learn the decision boundary. The linear and hybrid heads were retained as directional evidence; the encoder result is a named negative, not a hidden hyperparameter search.

6.3 Stentor-style recurrence lost to a minimal SSM

The ambitious Phase 2 hypothesis — that a Stentor-inspired recurrent core would beat a minimal diagonal SSM on language-modeling loss — failed: final loss was 5.21 versus 2.95 on TinyStories. The comparison was not clean: step counts and sequence lengths were unequal, and the association-trace update was sequential. The minimal core was promoted because it passed the no-regression gate, and the negative was logged with its confounds. The honest next experiment is a parallelized association scan at matched compute.

6.4 A false regression caused by the evaluation harness

After QLoRA training, the adapter path appeared broken: base 0.100 and +LoRA 0.200. The model was not the problem. A hash embedder combined with a minimum score of 0.15 filtered out the preference line, returning zero memories; switching the eval embedder to fastembed restored both paths to 1.000. The correction was written into the phase report. The lesson is now a first-class check: inspect retrieved-item counts before interpreting an end-to-end score.

7. Limitations and threats to validity

  • Small, synthetic benchmarks. The preference tasks are controlled and synthetic. They test a narrow memory behavior, not general assistant quality.
  • No external users. Daily utility is a qualitative single-user observation; there is no retention or satisfaction study.
  • Seed asymmetry. Headline results use three seeds; Phase 2 integration checks are seed 0 only. A skeptical reviewer should treat those as directional.
  • Small verifier labels. The learned/hybrid verifier result is n=13 and is not paper-grade. The encoder negative is similarly small.
  • Matched-budget scope. The headline claim is about naive RAG at a matched budget. Full-context raw LLMs remain stronger on the harder stress bench.
  • Hardware and cost. Results come from one consumer GPU and one ~$8 cloud burst; no multi-hardware replication.
  • Privacy boundary. The system is local by default and supports optional encryption at rest, but the encryption path has not been independently audited.
  • Source verification. This draft was prepared from the staged research record; every table should be reconciled against the repository and run directories before publication.

8. Conclusion

LSM shows that a compact, inspectable memory wrapper can produce a large gain over naive RAG at a matched context budget, and that the writer gate is the component most likely to matter when memory is under decoy pressure. The result is deliberately bounded: it does not claim to beat full-context models, and its negative results are part of the contribution. The next steps are matched-compute recurrence experiments, a larger verifier corpus, multi-seed Phase 2 integration, and a public, reproducible release of the code and run artifacts.
