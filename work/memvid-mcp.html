Case study · No. 03

MemVid MCP

Archived 2026Model Context Protocol · Memvid

An MCP server that condensed text into searchable memory banks, giving AI assistants persistent context without spending the context window.

The problem

AI assistants reread the same files every session. That burns context and repeats work. MemVid MCP turned a project's files into a persistent, searchable memory bank that the assistant could query instead.

Constraints

  • MCP clients speak JSON-RPC over stdio, not HTTP.
  • Memory banks must persist on disk and update incrementally.
  • Search has to be fast enough to be used mid-conversation.

Decisions

  • TypeScript MCP server + Python MemVid. The server owns the protocol and tool surface; the Python library owns MP4 encoding and vector search.
  • Memory banks as files. MP4 videos, FAISS indices, and JSON metadata on disk keep the bank portable and inspectable.
  • Auto-configuration. A CLI check and Cursor setup path reduced installation to one npx command.

Evidence

Published to npm and benchmarked at 57× faster startup and 1,900× faster cached search, with sub-second cached responses. Archived when the upstream MemVid format was deprecated, and kept as a case study rather than deleted.

Limits

The upstream MemVid format was deprecated, so the server was archived rather than maintained. It remains a working record of the protocol, packaging, and performance work.
