Case study · No. 01

Global Information Portal

Live · CompletedD3.js · TopoJSON

An interactive 2D map of the world. 240+ countries, 100+ metrics each, drawn from the CIA World Factbook and rendered entirely in the browser.

The problem

Country data is usually spread across pages, tables, and PDFs. The portal puts the map first: select a country, then read its metrics, rankings, and comparisons without leaving the page.

Constraints

  • No backend: everything runs in the browser.
  • 240+ countries with 100+ metrics each is too much to load at once.
  • The first country view has to feel immediate, including on repeat visits.

Decisions

  • Static application, D3 map. A Webpack bundle ships the map, panels, and charts; there is no server to operate.
  • Progressive pre-cache. Priority countries (G20, NATO, BRICS, and similar) are cached early; the rest load on demand.
  • One state layer. Country selection, panels, and charts read from the same state, so a map click updates the whole view consistently.

Evidence

Progressive caching halved the initial load; repeat visits land under a second. The record covers 240+ countries with 100+ metrics from the CIA World Factbook.

Limits

The portal is client-only and depends on the public Factbook JSON, so data freshness is tied to the upstream repository. There is no account layer or server-side aggregation.
